This walkthrough takes about ten minutes. By the end you will have a project with three actions, a plan for today, one answer from Zoe, and a way to capture actions from your phone or browser.

## 1. Sign in

Go to [/signin](/signin). Sign in with Google or Discord, or enter your work email and use the sign-in code it sends you. Some installations also offer Microsoft.

![The sign-in page: Google, Discord, or a work-email sign-in code](/doc-assets/signin.png)

You land in your personal workspace. Every account has one; teams and clients get their own workspaces later.

## 2. Meet the sidebar

![Workspace home with the sidebar open](/doc-assets/home.png)

The sidebar has three items that are always there, then four sections:

| Item | What it is |
|---|---|
| **Inbox** | Actions with no project or date yet |
| **Today** | The actions due or scheduled today, with a timeline of your day |
| **Time** | Your timer and time entries |
| **Align** | Goals, Decisions |
| **Deliver** | Actions, Projects, Pages (plus Products and Metrics when the Product Management plugin is on) |
| **Connect** | CRM |
| **Amplify** | Agents, Meetings, Knowledge |

The workspace switcher is at the top; your user menu (Settings, Teams, Journal, Workflows and more) is at the bottom. You can rename, reorder and hide sections and items under [Settings → Navigation](/settings).

## 3. Create a project

1. Open **Projects** under **Deliver** in the sidebar.
2. Click **New project**.
3. Give it a name. Status defaults to **Active**; set a **Priority** if you like. Product, goals and dates are optional.
4. Click **Create Project**.

![The New project form](/doc-assets/new-project.png)

## 4. Add three actions

1. Press **⌘N** (or click **Create Action** at the top of the sidebar).
2. Type the action, for example "Draft the brief". Add a description if you want.
3. Pick a priority (the first control, which defaults to **Quick**), set a **Date** if you like, and choose your project under **Select a project**.
4. Click **New action**, then repeat twice.

![The Create action dialog](/doc-assets/create-action.png)

Actions without a project or date go to **Inbox**; you can file them later.

## 5. Plan today

Open [Today](/today). Overdue actions sit at the top with a **Reschedule all → Today** button; the right-hand column shows your calendar for the day. Use **Add task** at the bottom to add something directly to today. **Plan** at the top right opens the [daily plan](/docs/do/daily-plan), a short wizard that walks you through choosing the day's focus (you can plan today or tomorrow).

![Today with the day timeline](/doc-assets/today.png)

## 6. Ask Zoe one question

Click **Ask Zoe · ⌘J** at the bottom right of any page. Try "What should I focus on today?" or "Break the brief project into steps". Zoe answers in the drawer, can create the actions she suggests, and remembers the thread; **New thread** starts a fresh one.

![The Zoe drawer](/doc-assets/zoe-drawer.png)

The full chat page is **Agents** under **Amplify** in the sidebar. See [Zoe](/docs/zoe/assistant).

## 7. Capture from anywhere

Pick one:

- **iPhone, iPad or Mac:** install the [iOS shortcut](/docs/capture/ios-shortcut) to add actions by voice or text from anywhere.
- **Browser:** install the [Chrome extension](/docs/capture/chrome-extension) to capture from any tab.
- **Phone, no install:** add Exponential to your home screen as a [mobile app](/docs/capture/mobile-app).

Each of these needs an API key from [Settings → API keys](/settings/api-keys); the guides walk you through it.

## FAQ

**Which sign-in methods are there?**
Google, Discord and a work-email sign-in code on exponential.im. Microsoft appears on installations that have it configured. You can link Google, Discord and Notion to one account under Settings → Profile.

**I typed an action but cannot find it.**
Actions without a date or project are in [Inbox](/inbox). Actions with a date appear on Today on that date and under **Upcoming** before then.

**Can I use this on my phone?**
Yes: the web app works on phones, and the [mobile app](/docs/capture/mobile-app) guide shows how to install it to your home screen.
